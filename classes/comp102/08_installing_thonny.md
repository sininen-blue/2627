# Thonny

---

## Thonny

Thonny is an **IDE** (integrated development environment) built for learning to 

<img src="https://i.imgur.com/pOGZk2f.png" class="mx-auto rounded w-1/4">

We'll be using it here because
1. It's easy to get started and removes information that's not relevant as a beginner
2. Features interactive debuggers to see what code is doing
3. Includes beginner friendly syntax errors and code completions

It's also *portable* so we don't need to install anything

---

## Step by Step

1. https://thonny.org/
2. hover over the windows button

<img src="https://i.imgur.com/JRBNSd1.png" class="mx-auto rounded w-1/4">

3. select the **portable** version

<img src="https://i.imgur.com/5W69o0z.png" class="mx-auto rounded w-1/4">

4. **UNZIP** the file, using winRar or whatever tool is installed in the computer

5. run `thonny.exe`
