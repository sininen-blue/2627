What determines the output of a combinational circuit?

- The current input values only
- The current inputs and the previous state
- The previous state only
- A stored history of past inputs

---

What distinguishes a sequential circuit from a combinational circuit?

- Its output depends on current inputs and past state
- Its output depends only on current inputs
- It uses only logic gates and no memory
- It always produces the same output for the same inputs

---

What is an example of a sequential/memory circuit?

- Flip-flop
- Multiplexer
- Adder
- Decoder

---

What does a multiplexer do?

- Selects one of several inputs and forwards it to a single output
- Routes a single input to one of several outputs
- Sets exactly one output line high based on an input number
- Compares two input words for equality

---

With n control pins, how many data inputs does a multiplexer have?

- 2^n data inputs
- n data inputs
- 2n data inputs
- n^2 data inputs

---

In a multiplexer, what role do the control pins play?

- They select which data input reaches the output
- They store the circuit's previous output value for later use
- They compare two input words to check for equality
- They enable every data input line to pass through at once

---

What is the purpose of abstracting a verified circuit into a labeled block?

- To show only inputs, outputs, and function
- To redesign the circuit's gate-level logic
- To convert the circuit into a sequential circuit
- To remove the need for control pins

---

What does a demultiplexer do?

- Routes a single input to one of several outputs
- Selects one of several inputs and forwards it to a single output
- Sets exactly one output line high based on an input number
- Compares two input words for equality

---

What does a decoder do with its output lines?

- Sets exactly one of 2^n output lines to 1 based on the input number
- Sets all output lines to 1 simultaneously
- Selects one of several inputs and forwards it to a single output
- Compares two input numbers and outputs their difference

What gate is used in a comparator to test if two bits are equal?

- XOR gate
- NOR gate
- AND gate
- Decoder
