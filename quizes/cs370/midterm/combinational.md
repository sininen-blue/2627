What determines the output of a combinational circuit?

- The current inputs alone
- The inputs and past state
- A stored memory value
- The previous output value

---

What distinguishes a sequential circuit from a combinational circuit?

- Its output depends on past state and current inputs
- Its output changes only when clocked
- Its output depends on current inputs only
- Its output has no relation to its inputs

---

What does a multiplexer do?

- Selects one of several inputs and sends it to one output
- Routes a single input to one of several outputs
- Compares two input words for a matching equality
- Selects exactly one output line for an input number

What is the purpose of abstracting a verified circuit into a labeled block?

- To hide internal gate-level detail while showing inputs and outputs
- To remove the circuit's inputs from the diagram entirely
- To convert the circuit into a sequential circuit design
- To increase the number of visible internal gate connections

- Routes a single input to one of several outputs
- Selects one of several inputs into a single output
- Compares two input words for a matching equality
- Enables multiple output lines at the same time
