What is a primitive in a programming language?

- A value treated as built-in and indivisible
- A value that bundles several others together
- A value that can change its type freely
- A value that is only checked at runtime

Which of these is an object or composite rather than a primitive?

- A List
- An int
- A boolean
- A double

When are types checked in a statically typed language?

- Before the program runs, at compile time
- While the program runs, at runtime
- Only when a type error occurs
- Only when the value changes

---

What happens to a variable's type in dynamic typing?

- It is whatever value it currently holds
- It is fixed at declaration forever
- It must be declared before use
- It is checked before the program runs

---

What does strong typing do when types don't match?

- Refuses to silently convert them
- Silently converts them to fit
- Changes the value's type
- Ignores the mismatch

Why does 0.1 + 0.2 not equal 0.3?

- Floats are a finite binary approximation of decimals
- Floats round to the nearest whole number
- The plus operator is broken
- Binary can represent every decimal exactly

What is the rule of thumb for comparing floats?

- Compare with a tolerance
- Always use ==
- Convert to strings first
- Never compare them at all

What is a truthy value?

- 14
- 20
- 100

---

Why does 2 ** 3 ** 2 evaluate to 512?

- ** is right-associative, so it is 2 ** (3 ** 2)
- ** is left-associative, so it is (2 ** 3) ** 2
- Exponent is evaluated after addition
- Exponent always comes before parentheses

- A single atomic value like one number
- A bundle of multiple values
- A value that can be looked inside
- A list of primitives
